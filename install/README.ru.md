# CAstrated

Эти сертификаты нужны, чтобы несколько сайтов Минцифры открывались **без** доверия официальному Russian Trusted Root CA для всего остального интернета.

**Доверяйте только сертификату в `trusted/`.** Файлы в `untrusted/` — промежуточные: их нужно установить, но **не** включать «Всегда доверять» / полное доверие к корню.

Разрешены `rzd.ru`, `gosuslugi.ru`, `gov.ru`, `sberbank.ru` и `sbrf.ru` (включая поддомены). Если в сертификате сайта есть ещё какое-то DNS-имя, проверка не пройдёт.

## macOS

1. Откройте **Связку ключей**. Нужна связка **входа** (login).
2. Откройте каждый `.crt` из `trusted/` и `untrusted/` (двойной щелчок или перетаскивание в Связку ключей).
3. Найдите **CAstrated Constrained Anchor**. Двойной щелчок → **Доверие** → для **Secure Sockets Layer (SSL)** выберите **Всегда доверять**. Остальное не трогайте. Закройте окно и введите пароль.
4. Для **Russian Trusted Root CA** и обоих **Russian Trusted Sub CA** оставьте доверие по умолчанию («Использовать системные настройки»). **Не** включайте «Всегда доверять».
5. Если раньше ставили официальный Russian Trusted Root CA с gosuslugi.ru/crt — удалите его. Иначе ограничения не работают.

Safari, Chrome и Dia берут эту связку. У Firefox своё хранилище: либо не используйте Firefox, либо добавьте те же сертификаты там (якорь — для сайтов, остальные — без доверия).

## iOS

Передайте `.crt` через AirDrop или откройте распакованную папку в **Файлах** и нажмите на каждый сертификат.

1. Сначала установите **CAstrated Constrained Anchor** из `trusted/`. iOS покажет профиль в **Настройки → Основные → VPN и управление устройством**. Установите его.
2. Так же установите каждый `.crt` из `untrusted/` (обрезанный корень и оба промежуточных).
3. Полное доверие включите **только** для якоря: **Настройки → Основные → Об этом устройстве → Доверие сертификатам** → включите **CAstrated Constrained Anchor**.
4. Профили Russian Trusted Root / Sub CA оставьте установленными, но **не** включайте их в «Доверие сертификатам».
5. Удалите старый профиль «Russian Trusted Root CA», если ставили его с официального сайта Минцифры.

Safari на iOS (и Chrome / Dia на том же движке) подхватит доверие после включения. Перезагрузка почти никогда не нужна; если сайт всё ещё не открывается, выключите и снова включите тумблер доверия.

## Если сайт не открывается

- Проверьте, что SSL / полное доверие включено **только** для CAstrated Constrained Anchor.
- Проверьте, что официальный неограниченный корень **не** в доверенных.
- Кнопка «Показать сертификат» в Safari или Chrome может аварийно закрыть браузер. Это ошибка просмотрщика Apple, а не признак, что сайт недоверенный. Замок при этом может быть в порядке.
